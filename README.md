# Fichas de rol v2 — propuesta de mejora

Página estática con la propuesta de rediseño de las fichas de arquetipo por rol:
del rol descrito como lista de tareas al rol definido por su misión, su tensión, su
límite y la evidencia con la que gana XP.

Incluye:

- Diagnóstico: qué se conserva y cuál es el problema de fondo (guía vs. aduana).
- Estructura propuesta en seis bloques.
- La ficha del Líder Técnico reescrita, antes y después.
- Tres misiones con evidencia y el cambio en el motor de XP (primer intento → corrección).
- Dos indicadores del sistema de trabajo y las decisiones pendientes.

## Ver

- Publicado en GitHub Pages.
- Local: abrir `index.html` en el navegador (sin dependencias externas).

## Imprimir

La hoja de estilos incluye reglas `@media print` (A4): desde el navegador,
Imprimir → Guardar como PDF.
